# CodeForFire

Open-source software built by firefighters, for firefighters.

CodeForFire is a volunteer community founded in Bavaria, Germany. We develop practical software that supports emergency responders during real operations. Our projects are developed in English, while applications are optimized for German fire departments and can be translated into other languages.

## Projects

### LageBuch

A digital incident management system for use inside an ELW (Einsatzleitwagen).

- Incident log
- Resource tracking
- Unit status
- Task management
- Offline-first
- Open source
